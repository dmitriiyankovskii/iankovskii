Создание SSH ключа: 
1. ввести в терминале команду ssh-keygen -t ed25519 -C "имя пользователя"
2. при создании выполнить все требования в терминале
3. зайти в github в настройки аккаунта во вкладку SSH and GPG keys и ввести текст из файла с расширением .pub
4. в терминале ввести команду ssh add "путь к файлу, где расположен приватный ключ"
